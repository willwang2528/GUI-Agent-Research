# Step 5：环境证伪

> status: **LOCKED BY STEP 4**

## 要回答的问题

在旧 evidence 完全相同的条件下，真正的新环境证据能否使 contract 失效、传播 dependent obligations 并触发恢复；这是否优于 generic reflection 或 context refresh。

## 必要对照

- same old evidence + reflection；
- new environment evidence + no invalidation；
- new evidence + invalidation only；
- new evidence + propagation/recovery；
- world-truth change、goal change、corrective feedback 与 hidden-fact revelation 分开。

## 当前结论

C0-E pure-world burden 尚未测量，环境题名仍是待证假设。

## Kill condition

若 pure-world 子集低于 global frozen gate，必须强制改名为一般 Evidence/Update-to-Action Consistency；不得保留 Environment-Falsifiable 主标题。
