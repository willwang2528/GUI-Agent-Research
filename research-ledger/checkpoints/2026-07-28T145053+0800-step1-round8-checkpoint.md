## 4. Round 8 的第一性证明

### 4.1 Maximum cardinality 只修复 greedy，不建立 identity

在边集合 `{a1-b1,a1-b2,a2-b1}` 上：

```text
greedy a1-b1                → a=1,b=1,c=1 → agreement=0.5
maximum a1-b2 plus a2-b1    → a=2,b=0,c=0 → agreement=1.0
```

所以 maximum cardinality 是防止 greedy under-match 的必要条件。

### 4.2 同 cardinality 的 maximum matchings 仍改变结论

`K2,2` 中：

```text
aligned maximum matching → exact agreement=2
cross maximum matching   → exact agreement=0
```

两者 cardinality 都是 2。deterministic tie-break 只能保证复现，不能产生 semantic validity。

### 4.3 Split/merge 改变 event denominator

一位标注者提交 coarse `{O1,O2}`，另一位提交两个 atomic `{O1}`、`{O2}`。case count 可被写成 1 或 2；任何强制 one-to-one matching 都在暗中选择 event ontology。因此 split/merge component 必须标为：

```text
SEGMENTATION_ESTIMAND_UNIDENTIFIABLE
```

不得生成伪 event-level numeric upper。
